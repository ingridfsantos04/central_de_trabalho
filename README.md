# central_de_trabalho
Central de Trabalho IA é uma plataforma pessoal de produtividade desenvolvida para organizar demandas profissionais, projetos, prazos, agentes de inteligência artificial, prompts, documentações e testes. O objetivo é centralizar informações, acompanhar atividades e facilitar o gerenciamento do trabalho em um ambiente moderno, intuitivo e eficiente.
